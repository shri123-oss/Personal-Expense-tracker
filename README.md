# Personal Expense Tracker 💰

A beginner-friendly Java console application to record daily expenses, organize spending by category, and calculate total expenditure.

## Features

* Add expenses with a name, category, and amount
* View all recorded expenses
* Calculate total spending
* View expenses by category
* Validate expense amounts and menu choices

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList and Collections
* Scanner for user input

## How to Run

1. Install the Java Development Kit (JDK).

2. Download `ExpenseTracker.java` from this repository.

3. Open a terminal in the folder containing the file.

4. Compile the program:

   ```bash
   javac ExpenseTracker.java
   ```

5. Run the application:

   ```bash
   java ExpenseTracker
   ```
